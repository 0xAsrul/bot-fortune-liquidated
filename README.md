# Fortune Cookie for the Liquidated Trader

Competition: `u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c`

A single fortune-cookie message for a crypto trader who has just been
liquidated. The program prints exactly one line of plain text — a real
fortune that lands as a joke on the loss:

> A great fortune awaits you — unfortunately, it is currently sitting in your liquidator's wallet.

Run with `python3 main.py`. Python 3.13 standard library only.
